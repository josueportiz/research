# BSc Thesis: Intelligent Monitoring System for Teaching Laboratories

## General information

- **Recommended degree:** BSc in Computer Engineering (Computing or Software Engineering track).
- **Co-supervisor (if applicable):** Dr. Laura Martín (Electronics Department).
- **Industry partner (if applicable):** TechLab Analytics S.L.

## Introduction and problem context

Teaching labs generate heterogeneous data sources (sensors, incidents, equipment usage) that are rarely integrated into a single analysis workflow. This limits early fault detection, resource optimization, and evidence-based continuous improvement. The thesis proposes the design of a data-driven platform for collection, analysis, and visualization to support operational and academic decision-making.

## Specific objectives

1. Design a data acquisition and storage architecture for laboratory sensors and event logs.
2. Implement a processing pipeline with health metrics and early-warning alerts.
3. Develop a web dashboard for KPI visualization and historical traceability.
4. Evaluate the prototype on a real use case and define scaling improvements.

## Planned technologies and tools

- **Languages:** Python, SQL, TypeScript.
- **Hardware:** Raspberry Pi and environmental sensors (temperature, humidity, CO₂).
- **Libraries and frameworks:** FastAPI, Pandas, scikit-learn, Plotly, Docker.
- **Supporting infrastructure:** GitHub, GitHub Actions, MkDocs for technical documentation.

!!! warning "Required skills and learning commitment"
    - Desirable prior knowledge of Python programming and Git-based version control.
    - Recommended baseline in descriptive statistics, data handling, and debugging practices.
    - Initial familiarity with REST APIs, containers, and reproducible deployment.
    - If these skills are not mastered at project start, the student **must explicitly commit** to guided self-learning (reading, hands-on practice, and tutoring sessions) to meet milestones on time and with expected quality.
