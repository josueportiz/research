# TFG: Sistema de Monitorización Inteligente para Laboratorios Docentes

## Datos generales

- **Titulación recomendada:** Grado en Ingeniería Informática (mención en Computación o Ingeniería del Software).
- **Cotutor/a (si aplica):** Dra. Laura Martín (Departamento de Electrónica).
- **Empresa colaboradora (si aplica):** TechLab Analytics S.L.

## Introducción y contexto del problema

Los laboratorios docentes generan datos heterogéneos (sensores, incidencias, uso de equipos) que rara vez se explotan de forma integrada. Esto dificulta anticipar fallos, optimizar recursos y documentar evidencias para mejora continua. El trabajo propone diseñar un sistema de captura, análisis y visualización para apoyar decisiones operativas y académicas con base en datos.

## Objetivos específicos

1. Diseñar una arquitectura de adquisición y almacenamiento de datos para sensores y eventos del laboratorio.
2. Implementar un pipeline de procesamiento con métricas de estado y alertas tempranas.
3. Desarrollar un panel web para visualización de indicadores clave y trazabilidad histórica.
4. Evaluar el prototipo con un caso real y definir mejoras para su escalado.

## Tecnologías y herramientas previstas

- **Lenguajes:** Python, SQL, TypeScript.
- **Hardware:** Raspberry Pi y sensores ambientales (temperatura, humedad, CO₂).
- **Librerías y frameworks:** FastAPI, Pandas, scikit-learn, Plotly, Docker.
- **Infraestructura de apoyo:** GitHub, GitHub Actions, MkDocs para documentación técnica.

!!! warning "Capacidades requeridas y compromiso de aprendizaje"
    - Conocimientos deseables de programación en Python y control de versiones con Git.
    - Base recomendable en estadística descriptiva, tratamiento de datos y depuración de código.
    - Familiaridad inicial con APIs REST, contenedores y despliegue reproducible.
    - Si estos conocimientos no se dominan al inicio, el/la estudiante **debe asumir explícitamente** un compromiso de autoaprendizaje guiado (lecturas, prácticas y tutorías) para cumplir los hitos en tiempo y forma.

## Fases orientativas y entregables previstos

1. **Fase 1 - Análisis y diseño (Semanas 1-4):** requisitos, arquitectura y plan de validación.
   - **Entregable:** documento de especificación técnica.
2. **Fase 2 - Implementación del prototipo (Semanas 5-10):** adquisición de datos, backend y dashboard inicial.
   - **Entregable:** repositorio funcional con manual de puesta en marcha.
3. **Fase 3 - Evaluación y mejora (Semanas 11-14):** pruebas con datos reales y ajuste de métricas/alertas.
   - **Entregable:** informe de resultados experimentales.
4. **Fase 4 - Cierre académico (Semanas 15-16):** memoria final y presentación.
   - **Entregable:** memoria TFG y diapositivas de defensa.
